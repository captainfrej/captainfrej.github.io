Politique de confidentialité — Peska

Dernière mise à jour : 13 juin 2026

Peska est une application de santé sexuelle conçue selon le principe du privacy by design : par défaut, vos données restent sur votre téléphone.

1. Le principe : vos données restent sur votre appareil

Vos résultats de test, vos documents et votre journal de partenaires sont stockés uniquement sur votre iPhone (base locale chiffrée par iOS). Peska fonctionne sans compte et sans serveur pour ces données. Rien n'est envoyé à qui que ce soit sans une action explicite de votre part. Vos rappels (dépistage, PrEP) sont programmés localement via les notifications iOS — leur contenu (schéma, dates, stock) reste sur votre appareil.

2. Compte (facultatif)

La création d'un compte (e-mail, Google ou Apple) est optionnelle. Elle sert uniquement à sauvegarder vos données de façon chiffrée et les retrouver sur un nouveau téléphone. Si vous n'en créez pas, tout reste local. Avec « Se connecter avec Apple », vous pouvez masquer votre e-mail.

3. Partage de statut et notification aux partenaires

  • Le partage de votre badge se fait en pair-à-pair via QR code : les informations passent directement entre les téléphones. Vous choisissez ce que vous montrez (nom ou pseudonyme, résultat, IST, date).
  • Les alertes d'exposition anonymes : si vous êtes positif·ve, vous pouvez prévenir vos partenaires liés. Le message est anonyme — il ne contient ni votre nom, ni votre numéro. Le serveur ne voit qu'un identifiant de lien (aléatoire) et la liste des IST, jamais votre identité.

4. Vérification d'un compte-rendu de laboratoire (si vous l'utilisez)

Si vous demandez une vérification manuelle d'un PDF :

  • vous donnez un consentement explicite et spécifique au fait qu'un membre de l'équipe Peska consulte ce document une seule fois pour le vérifier ;
  • le PDF est stocké de façon chiffrée dans un espace privé, accessible uniquement par vous et le vérificateur ;
  • il est supprimé automatiquement après vérification (sous 7 jours) ;
  • nous ne conservons que l'attestation (vérifié oui/non, date, laboratoire), pas le détail clinique au-delà du nécessaire.

5. Statistiques d'usage (anonymes)

Pour améliorer Peska, nous mesurons des événements anonymes et agrégés (par ex. « une application a été ouverte », « un badge a été partagé »). Ces statistiques ne contiennent jamais votre nom, vos IST, vos résultats, ni de données de localisation. Le seul identifiant est un numéro aléatoire par installation, non lié à votre identité, hébergé sur notre infrastructure en Union européenne. Aucune donnée n'est partagée avec des tiers (pas de Google Analytics, pas de Meta). Vous pouvez désactiver ces statistiques à tout moment dans Réglages → Confidentialité.

6. Données de santé (Art. 9 RGPD)

Peska ne traite des données de santé que sur la base de votre consentement explicite et au strict nécessaire. Peska est un outil personnel de suivi et un « trust layer » — ce n'est pas un dispositif médical et ne fournit pas de diagnostic.

7. Vos droits

Vous pouvez à tout moment : exporter vos données, tout supprimer (Réglages → Supprimer toutes les données), retirer votre consentement, désactiver les statistiques. Pour exercer vos droits RGPD : frajchaieb00@gmail.com.

8. Hébergement

Données de compte et de synchronisation : hébergées dans l'UE. Pour l'hébergement de documents de santé en France, Peska s'appuie (ou s'appuiera en production) sur un hébergeur certifié HDS.
